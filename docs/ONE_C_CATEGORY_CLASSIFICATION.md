# Классификация категорий прайса 1С

Единственный допустимый список — `CANONICAL_PRODUCT_CATEGORIES` в
`api/services/product_categories.py`. WB и standard Excel не нормализуются
по этому списку. Внутренняя структура 1С сохраняется в `group_name`;
`Product.category` для импортируемых из 1С товаров всегда canonical.

Классификатор использует тип товара, ближайшую папку и затем верхние группы.
Правила описывают группы и семейства материалов, а не отдельные SKU.
В названии предпочтение получает сам товар, а не его упаковка/применение:
«праймер с кисточкой» — грунтовка, «смывка в бутылке» — растворитель,
«преобразователь ржавчины с распылителем» — антикор.
Если признаки начинаются на одном месте, выбирается более специфичный
(длинный) признак, например «уплотнительная масса» вместо общего уплотнителя.

Расширение покрывает сокращения «шлиф.», «полир.», «абраз.», предфильтры,
полумаски, средства защиты, полировальные материалы, сварочные материалы для
пластика, оснастку, рихтовочный инструмент, мебель/оборудование мастерской,
изоляцию, запчасти, антикоррозионные средства и колеровочные компоненты.
Различаются блоки с абразивным зерном P120 и многоразовые блоки/держатели.

## Подтверждённая владельцем политика каталога

- Однокомпонентные, аэрозольные, алкидные и специальные эмали относятся к
  «Краски базовые». Это категория каталога, а не утверждение о составе материала.
- Универсальные пигменты и колеровочные пасты, включая PALIZH POLYMER U и
  SYSTEMIX, относятся к «Краски базовые». Явно обозначенные 2К компоненты
  остаются в «Краски 2K».
- SRA — растворитель для переходов: «Растворители». Это правило по назначению,
  без привязки к коду конкретной позиции LE-770.

Для действительно неизвестных товаров нет общего fallback в «Расходники».
Смешанные папки «Разное», «001.Краски», ОРМИС, WIEDER KRAFT, FULLEN-POLYMER
и LENERGY сами по себе не являются основанием для присвоения категории.
Такая строка пропускается с предупреждением, существующий товар не изменяется.

## Проверка семейств по документации производителей

Hymax B-series — система базовых красок, включающая перламутровые и специальные
тонеры: [техническое описание Hyflow B-Series](https://www.hymaxrefinish.com/wp-content/uploads/HyMax/tdsmsds/lb/hyflow-b-series/tds/hyflow-b-series_lb.pdf).

Sikkens Autocoat BT 200 Topcoat Classic и LV 151 DTM используют отвердитель,
поэтому соответствующее семейство относится к 2К:
[BT 200](https://www.sikkenscv.com/content/dam/akzonobel-coatings/sikkenscv/pl/pl/pdf/200_Topcoat_Classic.pdf),
[LV 151 DTM](https://www.sikkenscv.com/dk/da/produkter/1-lags-toplak/lv-151-dtm).
Базовая система Autocoat BT 120 не включена в это правило.

Комплектные покрытия RAPTOR относятся к 2К; явный признак 1К и отдельные
аэрозольные эмали учитываются отдельно:
[техническое описание RAPTOR 2K](https://u-pol.com/wp-content/uploads/RAPTOR-Black-US-ENG.pdf),
[линейки RAPTOR](https://u-pol.com/en-us/brands/raptor/).

Для семейств MobiHARD ПУ и HARDMAX PUR используются технические описания
производителя КВИЛ:
[MobiHARD ПУ 234](https://cdn.vseinstrumenti.ru/instruction/nomenclaturecontent/202407/38280295.pdf/14776799_manual.pdf),
[HARDMAX PUR 232](https://cdn.vseinstrumenti.ru/instruction/nomenclaturecontent/202406/37607600.pdf/14522999_manual.pdf).

Гидроцилиндры в группе WIEDER KRAFT — части инструмента для кузовного ремонта:
[каталог производителя](https://wiederkraft.ru/wp-content/uploads/2018/02/widerkraft.pdf).

Универсальные пасты POLYMER U совместимы с различными 1К и 2К материалами,
поэтому их категорию определяет согласованная политика каталога:
[карточка производителя PALIZH](https://palizh.com/catalog-industry/pasty-kolerovochnye-promyshlennye/pasta-kolerovochnaya-palizh-polymer-u-7-seriya/?oid=60794).

## Воспроизводимый аудит без записи в БД

```bash
DB_ENGINE=sqlite3 .venv/bin/python manage.py audit_1c_categories \
  '/local/path/прайс 08.10.26 1с ОТПР — фото.xlsx' \
  --output-dir '/local/path/category-audit' \
  --expect-total 3968 --require-complete
```

Команда сохраняет `CATEGORY_AUDIT.md`, `category-audit.json` и
`unresolved-before.csv`. Чтобы дополнительно сопоставить исходные unresolved,
передайте `--baseline '/local/path/baseline-products.json'`. Baseline — массив
строк с `sku`, `name` и `category` либо `baseline_category`; JSON текущей команды
также можно использовать в следующем аудите как baseline.
Число `folder_total` считается по всем валидным товарным строкам с одинаковым
названием ближайшей папки. Полная hierarchy позволяет различить папки
«Разное» разных брендов. Команда не создаёт и не обновляет товары.

```bash

  api.test_product_import_1c api.test_product_import
```

Для полного интеграционного теста приватного файла, включая два последовательных
upsert всех 3968 товаров в тестовой БД:

```bash
AUTOTERRA_TEST_1C_WORKBOOK='/local/path/прайс 08.10.26 1с ОТПР — фото.xlsx' \
DB_ENGINE=sqlite3 .venv/bin/python manage.py test api.test_product_import_1c.RealOneCWorkbookTests
```

Без этой тестовой переменной проверка приватного файла пропускается; синтетические
регрессионные тесты продолжают работать в CI без коммерческих данных.
