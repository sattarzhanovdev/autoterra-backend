# Персональные скидки по брендам — 13 октября 2026

Реализация завершена и проверена локально. Push, развёртывание на production и сборка новых APK/AAB в этой задаче не выполнялись.

## Реализация

Добавлена ClientBrandDiscount: клиент, нормализованный бренд, процент и время изменения. Уникальная пара client/brand и ограничение процента 0–100 закреплены в БД. Миграция: **0057_clientbranddiscount**, после 0056_client_shop_markup.

Новый приоритет в существующем price_for_client:

**Персональная цена товара → скидка по бренду → общая персональная скидка → скидка по рангу → базовая цена.**

Проценты не суммируются. 0% — явное правило без процентной скидки; удаление записи возвращает общую скидку или ранг. Фиксированные персональные цены остаются первым приоритетом. Стоимость существующих заказов сохраняется; создание и замена заказа, а также добавление новых позиций при корректировке используют актуальный единый расчёт.

Бренд берётся из существующего Product.brand. Ключ нормализуется через Unicode NFKC, casefold и схлопывание пробелов. Названия товаров и существующий фильтр Django admin не переписываются. Один запрос правил на клиента кэшируется на время расчёта страницы, без запроса для каждого товара.

Правила не связаны с ID товара, поэтому переживают повторный импорт Excel. Исправлен импорт без колонки бренда или с пустым брендом: существующее значение больше не заменяется на AutoTerra. Новые товары сохраняют прежнее значение по умолчанию. Исчезнувший из активного каталога бренд остаётся в настройках, его скидку можно изменить/удалить.

## API

Один endpoint: `/api/clients/{clientId}/brand-discounts/`.

- GET: постраничный список брендов дистрибьютора клиента и существующих правил. Параметры search, discountsOnly, page, page_size. Поля строки: brand, label, percent, available; ответ также содержит canEdit и pagination.
- PATCH: атомарное добавление/изменение до 200 правил:
  `{"discounts":[{"brand":"LUKOIL","percent":"10"},{"brand":"MANN","percent":"15"},{"brand":"BOSCH","percent":"7.50"}]}`.
- DELETE: `{"brand":"BOSCH"}`; повторное удаление безопасно.

Администратор меняет любого клиента, активный дистрибьютор — своего. Менеджер читает данные своих регионов, но не изменяет их. Клиент, courier и ai_expert не имеют доступа к API управления правилами. PATCH/DELETE блокируют клиентскую запись и повторно проверяют принадлежность, используя существующую область прав общей скидки. Записи изменений сохраняются в AuditLog.

## UI

В карточках клиента добавлен блок «Скидки по брендам». Экран использует существующую пагинацию: поиск, фильтр установленных скидок, галочки для нескольких брендов, установка общего процента выбранным брендам, индивидуальное изменение и подтверждаемое удаление. Ошибки загрузки/сохранения не подменяются успешным результатом. Сохранение обновляет список без повторного входа. В сводной карточке обновляются персональные цены.

Открытые каталог, карточка товара и корзина получают свежие цены через существующий quote каждые 5 секунд и при обновлении. Flutter показывает серверную закупочную цену и не вычисляет брендовые скидки самостоятельно. Наценка магазина продолжает рассчитываться поверх конечной закупочной цены. В списке персональных цен видно применение брендового процента.

В Django admin добавлен inline ClientBrandDiscount в карточку клиента. Для staff-администраторов при использовании Django admin нужны обычные разрешения add/change/delete/view новой модели; superuser получает доступ автоматически. Менеджер не может изменять inline даже при наличии разрешения модели.

## После push

1. Обновить backend, в серверном виртуальном окружении выполнить:

   ```sh
   python manage.py migrate --noinput
   python manage.py check
   ```

2. Проверить, что миграция 0057 применена, затем перезапустить Django/Gunicorn штатной командой сервера. При необходимости выдать staff-администраторам права новой модели для Django admin.
3. Обновить Flutter-приложение после backend. При следующей сборке использовать свободный versionCode выше уже загруженного 12.
4. Проверить на устройстве клиента общую скидку 5% + BOSCH 10%, персональную цену товара, сброс брендового правила, корзину и оформление заказа. У уже открытого клиента обновление цены занимает до 5 секунд при наличии сети.
